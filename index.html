MCP 接入

启动小外挂，即可让 AI 编程工具操作当前线上工程，无需迁移设计数据。

下载外挂，在电脑上用 Node.js 运行下面的命令。保持外挂运行，再点击连接；浏览器询问时允许访问本机。

下载小外挂 
node protolab-mcp.mjs

在下载目录执行。需要 Node.js 20.11 或更高版本，无需安装其他依赖。

连接后，选择 Codex、Cursor、Claude Code、OpenCode 或 Antigravity，复制配置并合并到客户端配置文件，再重新加载客户端。调用期间保持标签页打开。
