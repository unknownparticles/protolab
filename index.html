新建工程

各工程独立保存页面、组件库、修改版本和 AI 对话。新建或切换前自动保存当前工程；切换会取消正在进行的 AI 请求。

AI 生成预览

AI 接口设置

支持 OpenAI 兼容的 Chat Completions 接口。可填写基础地址或完整的对话接口地址。

地址和模型保存在本地；默认 Key 仅用于当前页面。勾选后 Key 以明文保存在浏览器中，不会进入版本备份或 HTML 导出。HTTPS 页面会将 HTTP 接口地址自动改为 HTTPS，接口须支持 HTTPS。浏览器直接请求接口，服务需允许本站跨域访问，以及 POST 方法和 Content-Type / Authorization 请求头。

历史记录

每一步设计操作都可撤回或重做，也可选择指定步骤恢复。撤回后继续编辑会替换后续历史；保存的版本继续保留。历史在本次打开期间按工程保留。

版本记录

保存（包括 Ctrl / ⌘ S）及 AI 生成前后形成版本。日常编辑进入历史记录，自动保存草稿不产生版本。回退后继续编辑会保留原来的分支，AI 合并版本保留两份来源。记录保存在此浏览器，可导出备份。

合并 AI 修改

互不冲突的字段已自动合并。冲突需要逐项选择；未选择时预览保留本地内容。

导入工程

支持工程 JSON 和 HTML。导入将替换当前画布，可撤销；建议先导出当前工程。工程 JSON 同时恢复自定义组件库。

普通 HTML 在此尺寸下计算布局并识别可见组件，保留内联和页面 CSS 样式。隐藏内容不导入，脚本不执行，外链样式、字体与图片不载入；请将资源内嵌。工程 JSON 和新版导出的 HTML 使用原工程尺寸。
