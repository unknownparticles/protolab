## 多工程与独立生成验收

`npm run test:projects` 使用本地模拟兼容接口验证工程创建、快速切换、独立组件库／画布／版本／对话、旧单工程迁移和刷新恢复；验证内置规范与工程规范注入，组件预览及复用、生成页面拆分编辑与撤销重做，工程名称／规范 JSON 往返。验证非法生成拒绝、切换取消请求、迟到响应隔离和存储失败时阻止切换。工程集合与工程导出均不包含接口 Key。

新增模型测试覆盖工程集合校验、快照隔离、待合并版本迁移、工程上限和独立生成协议。浏览器截图为 `test-results/projects-generation-preview.png` 和 `test-results/projects-mobile.png`。AI 模型响应使用测试桩，页面生成质量和实际接口连通性仍取决于用户配置的模型与服务。
