# 原型稿设计器 · 设计要求文档

以下是围绕 **Protolab**（暂定名）的完整设计要求，可直接作为产品/设计/开发的任务书。

---

## 一、产品定位

| 项目 | 说明 |
|------|------|
| **产品名称** | Protolab（原型实验室） |
| **一句话定位** | 浏览器里的轻量级原型设计工具，拖拽即出 HTML 原型 |
| **目标用户** | 产品经理、设计师、前端开发者、独立开发者 |
| **核心价值** | 零安装、零学习成本、导出即用、可挂载 GitHub Pages |
| **对标产品** | Figma（交互参考）、Excalidraw（轻量参考）、Webflow（导出参考） |

## 二、视觉设计要求

### 2.1 设计风格

- **关键词**：干净、工具感、专业但不冷峻
- **参考调性**：Figma 的中性灰 + Linear 的精致感 + Excalidraw 的亲和力
- **避免**：过度拟物、花哨渐变、卡通风格

### 2.2 色彩系统

```
主色（品牌色）    #2563EB  蓝色，用于按钮、选中态、强调
主色 hover       #1D4ED8
主色 light       #DBEAFE  选中背景、拖拽高亮

中性色
  背景           #F1F5F9  工作区背景
  面板           #FFFFFF  侧栏、工具栏
  边框           #E2E8F0
  分割线         #F1F5F9
  次级背景       #F8FAFC  组件卡片、hover态

文字色
  主文字         #0F172A
  次文字         #334155
  辅助文字       #64748B
  占位文字       #94A3B8

功能色
  成功           #16A34A
  警告           #F59E0B
  危险           #DC2626
  删除hover      #FEF2F2
```

### 2.3 字体

- **字体族**：`Inter, system-ui, -apple-system, sans-serif`
- **字号规范**：
  - 工具栏按钮 / 面板标题：13px，字重 500
  - 组件库名称：14px，字重 500
  - 属性标签：13px，字重 400
  - 状态栏 / 辅助信息：12px，字重 400
  - 区块标题（如"组件属性"）：12px，字重 600，大写，字间距 0.5px

### 2.4 圆角与阴影

| 元素 | 圆角 | 阴影 |
|------|------|------|
| 工具栏按钮 | 24px（胶囊） | 0 1px 2px rgba(0,0,0,0.02) |
| 组件库卡片 | 12px | hover: 0 4px 8px rgba(0,0,0,0.04) |
| 画布容器 | 16px | 0 20px 35px -8px rgba(0,0,0,0.15) |
| 画布内组件 | 8px（可调） | 0 4px 12px rgba(0,0,0,0.06) |
| 选中组件 | 8px | 0 0 0 3px rgba(59,130,246,0.3) |
| 输入框 | 8px | focus: 0 0 0 2px rgba(59,130,246,0.2) |

### 2.5 间距系统

- **基础单位**：4px
- **常用间距**：4 / 8 / 12 / 16 / 20 / 24 / 30 / 40
- **工具栏内边距**：12px 20px
- **侧栏内边距**：16px
- **组件卡片内边距**：12px 14px
- **画布区外边距**：30px

### 2.6 图标

- **图标库**：Font Awesome 6（免费版）
- **尺寸**：工具栏 14px、组件库 20px、空状态 40px
- **颜色**：跟随文字色或主色

## 三、布局设计要求

### 3.1 整体结构

```
┌─────────────────────────────────────────────────────┐
│  顶部工具栏（预设 / 方向 / 组件库 / 导出）              │
├──────────┬───────────────────────────┬──────────────┤
│          │                           │              │
│  左侧    │        中间画布            │   右侧       │
│  组件库  │      （可缩放、可滚动）     │   属性面板   │
│  280px   │                           │   260px      │
│          │                           │              │
├──────────┴───────────────────────────┴──────────────┤
│  底部状态栏（提示信息 / 组件计数）                      │
└─────────────────────────────────────────────────────┘
```

### 3.2 各区域职责

| 区域 | 职责 | 可调整 |
|------|------|--------|
| 顶部工具栏 | 全局操作：预设尺寸、横竖切换、组件库导入导出、导出HTML | 固定高度 |
| 左侧组件库 | 展示预设+自定义组件，支持拖拽 | 宽度可固定 280px |
| 中间画布 | 主工作区，展示原型、拖拽放置、选中编辑 | 自适应 |
| 右侧属性面板 | 编辑选中组件的属性、画布尺寸 | 宽度可固定 260px |
| 底部状态栏 | 操作提示、组件计数 | 固定高度 |

### 3.3 响应式断点（可选）

- **≥ 1200px**：三栏完整展示
- **900px ~ 1200px**：侧栏收窄（组件库 220px，属性面板 200px）
- **< 900px**：可考虑折叠为抽屉式（进阶需求）

## 四、功能设计要求

### 4.1 画布尺寸与方向

- **预设尺寸**：
  - 手机：375 × 667
  - 平板：768 × 1024
  - PC：1280 × 800
- **横竖屏切换**：一键翻转宽高，预设标签同步更新（如"手机 横屏"）
- **自定义尺寸**：右侧面板可手动输入宽高（100 ~ 2000px）
- **画布视觉**：白色卡片 + 圆角 + 阴影，顶部有 header 显示当前尺寸

### 4.2 组件拖拽

- **拖拽源**：左侧组件库卡片，`draggable=true`
- **放置目标**：中间画布，`dragover` 时显示蓝色描边高亮
- **放置坐标**：以鼠标在画布内的相对位置为准，边界自动约束
- **放置后**：自动选中新组件，右侧面板同步

### 4.3 组件操作

| 操作 | 方式 | 反馈 |
|------|------|------|
| 选中 | 点击组件 | 蓝色描边 + 阴影，右侧面板显示属性 |
| 取消选中 | 点击画布空白 | 描边消失，面板显示"未选中组件" |
| 移动 | 按住组件拖动 | 实时更新 left/top，属性面板同步 |
| 命名 | 右侧面板输入名称 | hover 组件时右下角显示名称标签 |
| 删除 | 右侧面板删除按钮 | 组件移除，计数更新 |

### 4.4 组件属性（右侧面板）

- **名称**：文本输入
- **位置**：X、Y 数字输入
- **尺寸**：宽、高数字输入
- **圆角**：数字输入（0 ~ 50px）
- **内边距**：文本输入（如 `8px 12px`）
- **外边距**：文本输入（如 `0` 或 `10px`）
- **操作**：应用按钮、删除按钮

### 4.5 组件库管理

- **预设组件**（7个）：
  - 按钮、文本、输入框、卡片、图片占位、SVG星星、头像
- **自定义组件**：
  - 新建 HTML 组件（输入名称 + HTML 代码）
  - 新建 SVG 组件（输入名称 + SVG 代码）
  - 导入图片组件（上传图片，转 base64）
- **保存/导入**：
  - 保存到 localStorage
  - 导出为 JSON 文件
  - 从 JSON 文件导入

### 4.6 导出 HTML 原型

- **导出内容**：将画布内所有组件按绝对定位还原为独立 HTML
- **导出样式**：内联样式 + 基础布局，保证浏览器打开即可见
- **文件命名**：`prototype.html`
- **下载方式**：Blob + `a.download`

## 五、交互与动效要求

### 5.1 微交互

| 元素 | 动效 | 时长 |
|------|------|------|
| 按钮 hover | 背景色过渡 | 0.1s ease |
| 组件卡片 hover | 上移1px + 阴影 | 0.1s |
| 组件选中 | 描边 + 光晕 | 0.1s |
| 画布尺寸切换 | 宽高过渡 | 0.2s |
| 组件名称标签 | 淡入淡出 | 0.1s |

### 5.2 状态反馈

- **拖拽到画布上方**：画布蓝色描边高亮（`drag-over`）
- **组件选中**：蓝色描边 + 外发光
- **组件 hover**：显示名称标签
- **空画布**：显示图标 + "从左侧拖拽组件到画布"提示
- **操作成功**：alert 提示（保存组件库、导入成功等）

### 5.3 光标规范

- 组件库卡片：`grab` / 拖拽时 `grabbing`
- 画布内组件：`move`
- 按钮/输入框：`pointer` / `text`
- 画布空白：`default`

## 六、技术实现要求

### 6.1 技术栈

- **纯前端**：HTML + CSS + 原生 JavaScript（无框架依赖）
- **图标**：Font Awesome 6 CDN
- **存储**：localStorage（组件库持久化）
- **导出**：Blob + FileReader

### 6.2 性能要求

- 首屏加载 < 2s（不含 CDN 图标）
- 拖拽帧率 ≥ 60fps（使用 `transform` 或直接 `left/top`）
- 组件数量 ≤ 200 时无明显卡顿

### 6.3 兼容性

- Chrome / Edge / Firefox / Safari 最新版
- 支持 GitHub Pages 静态部署（纯静态资源）
- 移动端可浏览，但拖拽编辑以桌面端为主

### 6.4 代码规范

- 单文件实现（便于 GitHub Pages 部署）
- CSS 使用 BEM 命名或语义化类名
- JS 使用 IIFE 隔离作用域
- 注释清晰，关键函数有说明
