# 易设 · Protolab

浏览器里的轻量原型设计器：从组件库拖拽搭建界面，编辑尺寸与布局，导出可独立打开的 HTML。纯静态 HTML、CSS、原生 JavaScript，无框架、无后端、无运行时依赖。

顶部语言选择支持「跟随系统」「中文」与「English」。首次打开跟随系统首选语言（中文地区使用中文，英文地区使用英文，其他语言回退英文）；选择会保存在当前浏览器。系统语言变化时自动跟随，显式选择优先。切换即时更新菜单、属性、提示和预览控件，保留未应用的表单输入及工程、页面、自定义组件和画布文案。中文品牌为「易设」，英文品牌为「Protolab」。

## 本地运行

需要 Node.js 20.11 或更高版本。无需安装依赖：

```sh
npm run dev
```

访问 http://127.0.0.1:4173。可用 `PORT=8080 npm run dev` 指定端口。由于源码使用原生 ES 模块，请通过 HTTP 访问编辑器；导出的 `prototype.html` 可直接双击打开。

## 已实现

- 手机 375 × 667、平板 768 × 1024、PC 1280 × 800；横竖切换和 100～2000 px 自定义画布。
- 横竖屏切换保留组件坐标、尺寸和间距；组件可分别配置横屏与竖屏时保持原样、旋转或隐藏。
- 23 个内置组件：14 个普通组件（按钮、文本、输入框、多行文本框、滑杆、选择控件等）和 9 个矢量图形（点、线段、矩形、圆形、椭圆、三角形、箭头、菱形、星星）；拖拽或点击添加。
- 手机全面屏/经典外框、平板窄边框/经典外框、电脑显示器/笔记本/浏览器窗口；支持隐藏外框和自定义 HTML 外框。
- 手机支持刘海、灵动岛、居中/左侧打孔摄像头及关闭遮挡，横屏转到左侧；摄像头覆盖实际屏幕，经典手机的摄像头位于外框。
- 手机和平板可选时间电量栏、手势横条或三键导航；时间与电量可编辑。外框和系统栏支持自动保存、撤销重做、预览及 HTML 导出。
- 位置、尺寸、0～50 px 圆角、内外边距；缩小画布时自动约束尺寸和位置。
- 25%～200% 缩放和适应窗口；放置与移动按实际画布像素计算。
- 可独立开关的像素标尺与画布网格；网格间距 5～100 px，显示设置在本地保存。
- Shift 多选、整组移动、复制和删除；相对画布或所选组件进行四边对齐、水平居中、垂直居中和整体居中，支持撤销重做。
- HTML、SVG 和图片自定义组件；搜索；组件库本地保存、JSON 导入导出；兼容原稿的旧格式。
- 草稿自动恢复、撤销重做、图层选中与排序。
- 新建与切换工程；各工程独立保存页面、组件库、修改版本、对话和 AI 设计规范，兼容已有单工程草稿。
- 多页面、弹窗与 Toast 管理：新增、切换、复制、重命名、删除与首页设置，每页独立保存画布和组件。
- 组件点击可跳转页面、返回上一页、打开或关闭弹窗、显示 Toast，以及控制多个元素显示隐藏；预览和独立 HTML 导出均可交互。
- AI 对话修改：配置兼容接口的 URL、Key 和模型，按固定 JSON 变更协议更新画布。
- AI 独立生成组件或页面：结合用户提示词、内置设计规范与工程规范，预览后保存到组件库或添加为新页面。
- 持久修改版本、回退与分支保留；等待 AI 时继续编辑，返回后通过三方合并处理冲突并预览结果。
- 工程 JSON 导入导出，包含画布、设备外框、安全区和自定义组件库；导出的 HTML 可重新导入恢复编辑。
- 普通 HTML 导入按指定设计尺寸识别可见文本、控件、图片、SVG 和容器，保留页面 CSS、内联样式、变量以及 Flex/Grid 布局结果，组件可独立选择、移动和修改属性。
- 预览与 HTML 导出共用结构和样式；导出无外部 CDN 依赖。
- 小屏折叠侧栏；键盘操作、焦点提示、低动效模式。

## 操作说明

顶部操作收纳为「文件 / 编辑 / 画布 / 工具」一级菜单和二级下拉菜单：文件包含新建工程、工程设置、保存版本与导入导出；编辑包含撤销、重做、复制和删除所选组件；画布包含设备预设、横竖屏切换和适应窗口；工具包含 AI 对话与 AI 设置。工程切换、保存状态及预览仍在顶部。点击菜单展开，打开后可用鼠标横向切换；方向键导航，Home / End 跳到首尾，Esc 收起并返回菜单按钮，Tab 离开菜单。无可用操作时对应菜单项禁用，窄屏下菜单入口换行显示。

顶部工程下拉框用于切换工程。「新建工程」填写名称、初始设备和可选 AI 设计规范，创建后自动切换到空白工程；每个工程独立保存页面、组件库、版本和对话，最多 50 个。「工程设置」可修改名称和规范。切换前立即保存当前工程，保存失败时保留当前工程；本次打开期间各工程独立保留可撤回的历史，保存的版本可在「版本记录」中查看和回退。旧草稿、组件库、版本和对话自动作为首个工程保留。工程 JSON 包含工程名称和规范，导入时恢复。

在「AI 对话」选择「独立生成组件」或「独立生成页面」，输入提示词即可从空白生成画布开始设计。左侧组件库及画布上方也提供快捷入口。系统自动注入静态内容、可编辑拆分、文字层级、配色和间距等内置规范，并注入当前工程填写的规范；可在 AI 面板查看内置规范，在「工程设置」编辑工程规范。组件结果可修改名称后保存到当前工程组件库，再点击或拖拽使用；页面结果作为新的可编辑页面添加，可撤销或回退。生成结果须通过协议校验和内容清理，预览通过后再确认保存。接口地址、模型和 Key 通过「工具 → AI 设置」配置，各工程共用接口设置。

工程设置可关联「清爽蓝」「商务紫」「自然绿」或自定义配色，并编辑主色、辅助色、背景、正文与边框等七种颜色；组件库可选择全部、自定义、指定分组或不关联。轻量清单自动同步组件名称、类型、默认宽高、分组及方向响应等基础属性，可以预览并导出 `protolab-library-manifest.json`，不包含组件代码或图片内容。安全区可遵循当前页、使用工程四边留白或不限制。关联设置按工程隔离并随工程 JSON 导入导出；保存设置后，下一次 AI 修改或新页面生成会应用关联安全区，可复用组件以自身尺寸生成。

AI 的三种模式都会发送关联配色、轻量组件清单、安全区可放置范围和设备尺寸。AI 可用 `libraryId` 引用清单中的组件，由本地从请求时的组件库快照还原真实内容；引用范围外的标识会被拒绝，等待期间修改组件库也不会改变此次引用内容。配色与尺寸要求写入生成提示，实际设计效果仍需在预览中确认。

独立生成不携带已有画布组件或历史对话。生成期间可以继续编辑，原有页面内容保留；切换工程会取消正在进行的请求，迟到响应不会修改其他工程。已返回的待合并版本随所属工程保留；独立生成的预览结果保存前仅在内存中，请保存后再刷新或切换。

点击或拖拽左侧组件到画布，右侧输入属性后点击「应用属性」。画布上的组件按住可移动，点击空白取消选中。自定义组件保存后会自动写入当前浏览器，组件库的「导出」生成 `protolab-library.json`，「导入」校验整个文件后确认替换自定义组件，内置组件和画布内容保留。读取旧组件库时自动补齐内置组件。

「画布 → 横竖屏切换」只交换画布宽高，保留每个组件的 X、Y、宽高和组件间距。超出新屏幕的部分会被裁切，切回后恢复显示；刷新和工程往返也保留原布局。手动更新画布尺寸、选择设备尺寸预设或重新应用安全区时，会按新边界约束组件。

在新建 HTML、SVG 或图片组件时，可启用「跟随屏幕方向」，分别选择竖屏和横屏时的动作：保持原样、顺时针旋转 90°、旋转 180°、逆时针旋转 90°或隐藏。画布中的组件继承此设置，并可在右侧属性中单独修改后点击「应用属性」。旋转围绕组件中心，保留设计坐标与尺寸；隐藏组件仍保留在图层中，可以选中修改或关闭响应。响应默认关闭，旧组件保持原样。预览与独立 HTML 导出呈现当前设计方向的结果，工程数据保留两种方向的配置。

点击「工具 → AI 设置」，可用「填写 DeepSeek 官方配置」自动填写 `https://api.deepseek.com/v1` 和 `deepseek-chat`，再输入自己的 DeepSeek API Key 并保存。快捷配置清空表单中的旧 Key，取消设置则继续使用原配置。也可填写 OpenAI 兼容的 Chat Completions 接口地址（基础 URL 或完整 `/chat/completions` 地址）、模型和 Key；无鉴权接口可留空 Key。Key 默认仅在当前页面内存中使用，也可选择在浏览器记住。点击「AI 对话」输入客户需求，系统发送固定格式提示词、当前项目和最近十二条客户及 AI 消息。响应须为版本 1 的 JSON 变更清单，支持新增、更新、移除组件，以及画布、外框和安全区调整；响应校验和内容清理通过后才应用。请求可取消，超时为两分钟，失败不影响当前设计。

每一步设计编辑（包括组件库修改）进入「历史记录」，支持撤销、重做及跨步恢复；历史在本次打开期间按工程保留，撤回后新编辑替换后续步骤。「文件 → 保存版本」、Ctrl / Command + S 及组件保存会生成版本，每次主动保存即使内容相同也新增记录。AI 生成前和成功返回后同样生成版本，确认应用独立生成结果及合并前后保留对应版本。自动保存、撤销、重做、工程切换和导入草稿不额外生成版本；草稿与版本分开存储，刷新继续恢复最新草稿。在「版本记录」中回退到旧版本后继续编辑，旧分支仍保留；AI 结果形成基于请求时版本的分支。请求期间如发生本地修改，AI 返回后等待用户确认合并；不同组件、不同字段自动合并，同字段修改或删除与编辑冲突须选择保留本地或采用 AI。合并窗口展示三份内容和最终预览，并记录两个来源版本。待合并结果刷新后继续保留，处理完成后可发送下一轮需求。版本备份包含最新草稿、全部版本、对话和待合并结果，导入追加原有版本；不含 Key、接口设置或组件库，组件库请通过工程导出另行备份。

画布上方可以新增「页面」「弹窗」或「Toast」，点击页签切换编辑。「管理当前页」可重命名、复制、删除，并将普通页面设为首页。弹窗默认 320 × 240 px，Toast 默认 320 × 100 px 并带提示文案；两者都使用独立画布，可调整尺寸和内容。三种画布合计最多 30 个，每页最多 200 个组件，切换时保留各自的尺寸、设备设置和组件；所有操作支持自动保存与撤销重做。删除画布会清除指向它的动作，撤销可一起恢复。

选中组件，在右侧选择「点击动作」与目标，点击「应用属性」。支持跳转至页面、返回上一页、跳转出弹窗、关闭弹窗和显示 Toast；Toast 可设置 200～10000 毫秒的显示时长，默认 2500 毫秒，到时自动消失，再次触发重新计时。Toast 也能在弹窗上显示。预览从当前编辑页开始；预览弹窗或 Toast 时在首页上自动展示当前内容，其中 Toast 持续展示以便编辑。导出的 HTML 从设置的首页开始，包含全部页面、弹窗和 Toast，直接双击也可操作。弹窗提供关闭按钮，支持 Esc 和点击遮罩关闭。AI 修改作用于发送请求时的页面，等待期间切换并编辑其他页也能合并。

「初始显示元素」控制组件在画布和预览中的初始状态，隐藏后仍可从图层选中编辑。「设置元素显示 / 隐藏」动作可选择当前页的多个目标，用「显示」「隐藏」或「切换」一起控制整个内容板块。默认开启「隐藏时收起布局空间」：隐藏内容释放纵向空间，同列的后续组件上移；显示时恢复原始布局，不积累偏移。重叠元素的高度只计算一次，同排仍有可见内容时保留其空间；其他列不受影响。关闭此选项仅隐藏内容并保留空间。坐标属性、对齐和吸附都使用当前显示位置，保存保留展开坐标。切换会统一整组状态；方向响应导致的隐藏保留原有布局。复制整组组件或整页时，显隐关联自动指向副本；删除目标时清理对应关联。

在「预览」中点击「编辑文字与尺寸」切换到编辑模式。双击文字后修改并点击「保存文字」；支持多段文字、输入提示、输入内容及矢量文字。选中组件后拖动四边或四角控制点调整尺寸，按 Esc 取消拖动。页面和弹窗中的修改同步回工程，支持自动保存、撤销重做及导出。再次点击编辑按钮即可体验点击跳转和弹窗交互。

「文件 → 导出工程」保存 `protolab-project.json`，用于完整备份和继续编辑。「导入工程」支持工程 JSON、原始草稿 JSON 和 HTML；导入将替换当前画布，画布变更可撤销。工程 JSON 同时恢复文件中的自定义组件库；HTML 导入保留当前组件库。新版导出的 `prototype.html` 自带工程数据，可精确恢复画布、组件和设备设置。

导入普通 HTML 前填写设计宽高（100～2000 px），用于媒体查询及响应式布局计算。页面样式计算后转为静态组件，不再响应原页面的 CSS 布局；隐藏元素不导入，空布局容器不生成图层。脚本不执行，外链样式、字体和图片不加载，建议使用页面内的 `<style>`、内联样式和内嵌图片。导入成功后会提示移除的内容。文件最多 32 MB；布局超过 2000 px、组件超过 200 个或文件校验失败时，保留当前设计。复杂的 CSS 变换、伪元素、裁剪及嵌套堆叠可能需要手动调整。

画布顶部的「标尺」「网格」可分别显示或隐藏，在右侧「画布设置」调整网格间距。标尺原点对应实际画布左上角，缩放和设备外框不会改变像素坐标。辅助线设置独立保存，预览和 HTML 导出只呈现原型。

按住 Shift 点击画布上的组件或右侧图层可增减选择。在「对齐与居中」选择参照：参照「画布」时，各组件分别对齐到画布边缘或中心；参照「所选组件」时，至少选择两个组件，以所选组件的包围框对齐。整体居中同时调整两个方向。多选后拖动或使用方向键会整组移动，触碰画布边界时保留组件相对位置。多选时属性表单只编辑最后点击的组件，复制和删除作用于所有所选组件。

右侧「拖动吸附」默认开启。拖动到可放置区域或其他组件的中心、边缘附近（屏幕距离 6 px 内）会自动对齐，并显示粉色参考线；多选按整体边界吸附。按住 Alt 临时跳过吸附，也可关闭开关。方向键仍按 1 / 10 px 微调。

右侧「安全区」可启用放置限制，设置上、下、左、右各 0～2000 px 的额外留白。上下留白从顶部系统栏以下和底部导航栏以上计算，并跟随系统栏实际高度变化。橙色虚线内为可放置区域；新增、拖动、复制、位置与尺寸编辑和对齐均受其约束，居中以该区域为参照。应用设置会移入越界组件并缩小过大的组件，设置和位置可一起撤销；缩小或旋转画布时留白自动收缩，至少保留 1 px 可放置空间。方向切换保留已有组件的设计位置；只修改名称、样式或方向响应也会保留被裁切的组件。安全区随草稿及工程保存，参考线不出现在预览和导出的页面中。

在右侧「设备外框」中选择样式。点击「编辑自定义 HTML 外框」可绘制装饰并设置四边留白（各 0～200 px），HTML 的 100% 宽高对应整个外框，画布按留白嵌入其中。支持静态 HTML / SVG 与内联样式。设备类型可独立于自定义画布尺寸选择。

手机全面屏或自定义外框下，可在「屏内摄像头」选择遮挡样式。摄像头显示在屏幕内容上方，设计时需留出安全区；旧草稿默认关闭，新建手机默认灵动岛。设置可撤销并随草稿保存，预览与导出保留同样遮挡。

顶部系统栏覆盖画布顶部 28～44 px（随摄像头样式变化），时间和电量避让摄像头；手势栏覆盖底部 28 px，三键导航覆盖底部 40 px，设计时请留出空间。电脑隐藏系统栏，切回手机或平板会恢复设置。

组件库按「基础」「矢量」「自定义」标签展示，搜索只展示当前分类的匹配结果；方向键可切换标签。保存新组件和 AI 生成组件后自动展示自定义分类。

选中组件后可修改宽高、上下左右独立的 padding / margin、背景色、矢量填充与描边颜色、不透明度和混合模式。文本组件提供逐段文案编辑，支持卡片标题及正文、表单提示与默认内容、下拉选项和 SVG 文字；字体、字号、字重和字体颜色留空时保留原样式。

图片占位、头像、独立图片及自定义组件中的图片均可上传或粘贴内嵌图片数据，多图组件可选择图片逐张替换。HTML 图片支持拉伸填充、裁剪填充、完整显示、原始大小和仅缩小；SVG 内嵌图片支持前三种。填充方式作用于组件内全部图片，混合模式作用于整个组件。上传后点击「应用属性」保存，支持撤销、刷新恢复、预览和工程／HTML 导出。每张上传图片最多 3 MB；内嵌图片另计大小，标记代码最多 100000 字符，单组件总内容最多 12 MB。浏览器存储配额仍有限，大图片和多次历史可能占满存储，未保存时可导出工程和版本备份。

画布尺寸不包含设备外框和编辑器的画板标题。X、Y 定义组件外框位置，内边距作用于组件外框，外边距作用于内部内容，不改变外框坐标。这保证边界约束和导出一致。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl / ⌘ Z | 撤销 |
| Ctrl / ⌘ Shift Z 或 Ctrl / ⌘ Y | 重做 |
| Ctrl / ⌘ D | 复制所选组件 |
| 方向键 / Shift + 方向键 | 移动 1 px / 10 px |
| Delete / Backspace | 删除所选组件 |
| Esc | 取消拖动及选择 |

在文本输入框、下拉框或弹窗内，编辑器快捷键暂停。

## GitHub Pages

将代码推送到远程 `main` 后，在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。工作流先执行测试与静态检查，然后只发布 `index.html`、`src/`、`styles/`。所有资源采用相对地址，可放在项目子路径。仓库文档及原始资料不进入 Pages 发布目录。

目标公开仓库为 `unknownparticles/protolab`，Pages 使用此工作流发布。后续每次推送 `main` 都会在检查通过后自动更新网站。

## 数据与边界

- 草稿、版本、对话和组件库保存在当前浏览器和站点来源；发送 AI 需求时会将当前项目内容和最近对话发送至用户设置的接口。无登录或团队同步。清除站点数据会删除本地记录，请使用工程 JSON 和版本备份保存。
- HTTPS 页面会在读取旧设置、保存设置和发送请求时将 HTTP 接口地址自动改为 HTTPS，接口须支持 HTTPS；本地 HTTP 页面保留原地址。AI 接口须允许本站来源的跨域请求，OPTIONS 预检及 POST 方法，并允许 Content-Type / Authorization 请求头；生产环境可填写自己的兼容代理地址。若控制台出现 Mixed Content，请改用 HTTPS；若 HTTPS 仍连接失败且预检返回 403，需要在接口服务端开放跨域访问或使用已配置跨域的兼容代理。浏览器扩展的 background.js / runtime.lastError 不属于本应用。勾选记住 Key 后以明文存入本地浏览器，不会进入导出文件。版本不自动清除，超过浏览器存储配额时会提示导出备份。
- 自动保存有 300 ms 合并延迟；页面隐藏和离开时也尝试保存。存储失败会明确提示，内存中的设计仍可导出。
- 单画布最多 200 个组件，组件库最多 200 个组件（包含 23 个内置组件）；库文件总大小最多 12 MB，单张图片最多 3 MB，单组件代码最多 100000 字符；本次打开期间记录全部设计操作，刷新后历史重新开始，已保存版本继续保留。
- 自定义组件支持静态 HTML、SVG 及常用内联样式。脚本、事件属性、外部资源、页面级样式和活动嵌入会被移除。SVG 中引用外部或内部 ID 的滤镜、渐变、`use` 等暂不支持；PNG / JPEG / GIF / WebP / AVIF 通过图片导入。
- 导出包含设备外框、系统栏、原型及组件，保留输入框等基础交互。响应式预览、组件嵌套、团队协作和 React / Vue 导出属于后续计划。
- 本次端到端验证使用 Chromium；Firefox、Safari 与 Edge 的人工验收仍待补充。200 组件压力测试不是所有设备达到 60 fps 的保证。

用户提供的原始资料保存在 `docs/`，用于追踪改进。授权范围尚未明确，未额外添加开源许可证。
